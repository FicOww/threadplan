# ThreadPlan 工作台

工作台复用 [行为合同](CONTRACT.md)。验收结果见 [VALIDATION](../reports/VALIDATION.md)。

## 启动和试用

```bash
python -B -X utf8 -m demo
python -B -X utf8 -m demo --check
```

打开 `http://127.0.0.1:8765/`。工作台只监听此回环地址。需要试多个实例时，分别指定 `--port` 和 `--state-dir`。默认状态在 `data/demo-local/`，其中包括各任务的规划记录、模拟日历和执行回执。

### 分享离线演示

直接分享构建后的 `ThreadPlan-离线演示.html`。双击用现代浏览器打开，页面不需要账号、服务或额外运行时。默认包含 12 个预设场景和 50 个历史开发回放。确认操作后，浏览器按验收时采集的结果更新本页的模拟日历。近期任务在支持文件页会话存储的浏览器中可刷新恢复。

无指定页面时先进入群聊导览。下方日历一开始显示原日程，确认改期后在原处更新，并可对照前后。导览结束后点「查看其他案例」进入同文件场景库；顶部也可直接打开场景库。导览使用预设示例，不调用模型、不连接真实日历，也不生成场景库的任务记录。

```bash
python -B -X utf8 -m scripts.build_offline_demo
```

构建时在独立目录运行 Python 工作台，采集已核验的场景视图、日历变化和回执。完整版本使用私有的 50 例回放归档。开发者可在本机提供 `runs/diversity50-replay/receipt.json` 及回执引用的归档。从公开仓库克隆或没有归档时，使用 `python -B -X utf8 -m scripts.build_offline_demo --builtin-only` 生成 12 场景版。原始运行、模型载荷、评分、凭据和台账留在本机。实际 Python 运行和实时模型沙盒使用本地服务入口。

| 方式 | 行为 |
| --- | --- |
| 内置场景 | 可通过 `--builtin-only` 独立运行。包含新增、改期、取消、多活动、候选澄清、跨午夜、未知写入、部分读取和其他故障。模型响应是明确标识的预设。 |
| 本地开发回放 | 若有已冻结的本地 campaign 回执，按输入与 fixture 哈希绑定 50 条历史案例。每次对照原消息、模型输入与内核实际读取事实。事实或场景变更导致不一致时显式失败。 |
| 自由试用 | 加 `--live-sandbox`，新写模拟笔记或填写合成对话 JSON。沿用本机配置的固定 OpenRouter 免费模型。每项最多三次模型尝试，同一时刻只接受一项。缺密钥时该模式不能启动。 |

真实飞书日历接入见 [飞书接入](FEISHU.md)。

首页可筛选与搜索场景。活动结果先显示目标、改动与下一步。模拟日历可切周、选日、查看时间块，并在「执行前／当前」间切换。变更经过执行与读回后显示新增、调整或移出的实际本地记录。回执未核验时，当前快照标明结果待核查。原消息、候选、查询和回执可在详情中核查。

## 任务、接口和可信执行

- 任务绑定浏览器会话与场景。回放采用固定业务时钟。命令期限随实际宿主时间推进。澄清创建一个新请求，保留原始消息和已派发回执。重置新建场景，使旧任务的待审批入口失效。
- 分析经 `ConversationPlanner` 和实际模拟读取。准备阶段复查基线，冻结并绑定当前活动与计划。逐项明确批准后调用 `PlanningExecutor`。本地 SQLite 模拟提供方复用 Feishu 日历编码和 journaled Host。这条路径从不调用原生 CLI。
- 写请求须同源。确认绑定任务、来源版本、命令、计划指纹和期限。相同场景的不同任务有独立回执索引。同一任务中重复确认复用原回执。未决沿原命令只读核查，未知 CREATE 无可靠 ID 时保持未决。
- 自由试用持久化输入和分析状态。重启后旧运行标为中断，可新建任务。模拟数据在 Git 忽略目录。到达模型的内容需在界面显式确认，原始模型轨迹留在本机。

| 本地 HTTP 路径 | 传参与结果 |
| --- | --- |
| `GET /api/scenarios` | 场景目录、历史回放与实时试用可用状态。 |
| `GET/POST /api/tasks` | 会话历史，或以 `{"scenario":"reschedule"}` 建任务。 |
| `GET /api/tasks/{id}` | 消息、活动、查询、模拟日历与命令状态。自由试用还返回模型状态。 |
| `POST /api/tasks/{id}/prepare` | 接收 `activity`，返回冻结命令。 |
| `POST /api/tasks/{id}/confirm`、`/recover` | 接收 `command`。批准执行，或沿原命令只读核查。 |
| `POST /api/tasks/{id}/clarify`、`/restart` | 选择预设回答，或重置合成场景。 |
| `POST /api/sandbox`、`/api/tasks/{id}/followup` | 提交合成笔记或合成导入，或继续对话。 |

## 真人任务对照

经许可记录真实任务的触发句、获得上下文的用时、目标、正确结果及失败代价。对照任务包含已有日程改期并保留字段、两个同名候选、一段对话多活动。另走读回失败和重复提交。先记录原生日历处理步骤，再对难度相近的任务交换体验顺序。记录正确目标及字段、从开始到核查的时间、澄清和返工。取得真实使用证据后更新报告。
